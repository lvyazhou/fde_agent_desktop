# 美迪康一体化 AI 办公平台 · 老板经营驾驶舱（原型 Demo）

桌面客户端风格的高保真可点击原型，给美迪康最高管理者（老板）演示用。

## 打开方式

⚠️ **不要直接双击 index.html**——浏览器会因 CORS 拦截 `fetch(data/*.json)`，页面数据为空。

**方式一（推荐）**：双击 `启动原型.command`，自动起本地服务并打开浏览器。

**方式二（命令行）**：
```bash
cd meidikang-cockpit-demo
python3 -m http.server 8770
# 浏览器打开 http://localhost:8770/index.html
```

## 页面清单（左侧竖直导航切换）

| 页面 | 文件 | 内容 |
|---|---|---|
| 经营驾驶舱 | `index.html` | 老板核心页。① 经营/效率指标 ② 各部门任务进展（泳道）③ 跨部门协同流（含卡点）④ 需老板介入事项（智能体主动推送）⑤ 工作质量评估 |
| 统一工作台 | `workbench.html` | 全员在用的平台工具入口（代码模式/专家广场/对话/知识库/技能/项目），+ 实时使用动态 |
| AI 网关 · 成本 | `gateway.html` | Token 用量与成本趋势、按模型分布、部门排行、成本明细表 |

## 可交互点（演示时可点）

- **经营驾驶舱**：点 KPI 卡看数据来源；点部门任务卡看智能体研判；点协同流「售前」看卡点如何阻塞下游研发；「需老板介入」点"一键处理"事项从列表消失；点质量评估看低分下钻。
- **AI 网关**：ECharts 图表真实渲染；成本明细可按部门筛选、翻页、点行看个人详情；导出按钮有 loading。
- 顶部窗口红绿灯、"● 智能体在线"、左侧"经营参谋正在盯盘"——体现桌面客户端 + AI 产品质感。

## 设计说明

- 外观：macOS 桌面客户端（窗口标题栏 + 左侧竖直导航），对齐平台本身是 Electron 桌面版的事实。
- 配色：深蓝商务，Token 化（改主色 = 改一行 `--primary`），支持暗色模式自动跟随。
- 数据：美迪康五部门（市场/销售/售前/研发/工程）+ 贴合医疗器械行业的示例任务，含卡点/预警/低分制造真实感。

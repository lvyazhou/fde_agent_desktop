# 美迪康一体化 AI 办公平台 · 老板经营驾驶舱（原型 Demo）

桌面客户端风格的高保真可点击原型，给美迪康最高管理者（老板）演示用。

## 打开方式

⚠️ **不要直接双击 index.html**——浏览器会因 CORS 拦截 `fetch(data/*.json)`，数据为空。

**方式一（推荐）**：双击 `启动原型.command`，自动起本地服务并打开浏览器。

**方式二（命令行）**：
```bash
cd meidikang-cockpit-demo
python3 -m http.server 8770
# 浏览器打开 http://localhost:8770/index.html
```

## 信息架构（左侧竖直导航，三大块）

### ① 经营驾驶舱
| 页面 | 文件 | 内容 |
|---|---|---|
| 经营驾驶舱 | `index.html` | 时间筛选 + 部门成本大盘（成本趋势/部门排行/模型分布）+ 经营全景（指标卡/部门任务泳道/跨部门协同流/需老板介入/工作质量评估） |
| AI 行为审计 | `audit.html` | 行为风险概览 + 人员行为审计表 + 点人下钻（工作摘要 / 每日工作时间线 / 合规风险研判） |

### ② 统一工作台（5 个功能模块，每个点进去可用）
| 页面 | 文件 | 内容 |
|---|---|---|
| 智能对话 | `chat.html` | 三栏聊天：会话列表 + 流式对话 + 预设问题 |
| AI 代码模式 | `code.html` | 文件树 + 代码区（语法高亮）+ AI 生成/重构面板 |

| 知识库 | `knowledge.html` | 分类树 + AI 检索问答（RAG）+ 文档列表 |
| 技能中心 | `skills.html` | 10 个技能卡，点运行演示"分步执行→产出" |

### ③ 设置
| 页面 | 文件 | 内容 |
|---|---|---|
| 网关设置 | `settings.html` | 接入模型管理 + 调用限额 + 数据安全 |

## 演示看点

- **驾驶舱**：时间条切换（今日/本周/本月/本季度）→ 指标跟着变；点协同流「售前」看卡点如何阻塞下游研发；「需老板介入」一键处理事项从列表消失。
- **AI 行为审计**：点「李蔓」看她的每日时间线——白天正经干活与写小说交替，违规内容标红；点「赵敏」看敏感数据外流告警。
- **工作台 5 模块**：智能对话流式打字；代码模式 AI 生成/重构；专家广场点专家进对话；知识库 AI 检索问答；技能中心点运行看分步执行。
- 全站体现"所有 AI 调用经网关审计、数据不出域"。

## 设计说明

- 外观：macOS 桌面客户端（窗口红绿灯 + 左侧竖直分组导航），对齐平台本身是 Electron 桌面版。
- 配色：深蓝商务，Token 化（改主色 = 改一行 `--primary`），支持暗色模式自动跟随。
- 数据：美迪康五部门 + 贴合医疗器械行业的示例，含卡点/预警/低分/违规制造真实感。

# 知识库配置规范

## 一、知识库类型

| 类型 | 内容 | 示例 |
|---|---|---|
| 内部知识库 | 企业专属数据 | 公司资质库、成功案例库、产品能力库 |
| 行业知识库 | 行业通用知识 | 政策法规库、行业标准库、术语字典 |
| 外部知识库 | 公开数据源 | 招投标法规库、行业报告库 |

## 二、配置步骤

| 步骤 | 内容 |
|---|---|
| 步骤一：梳理数据需求 | 问业务专家："你干这个活，需要查哪些系统？" |
| 步骤二：申请数据权限 | 向数据管理员申请访问权限 |
| 步骤三：准备数据 | 导出数据、清洗数据、格式转换 |
| 步骤四：切片规则 | 按表格层级、条款结构、段落语义切片 |
| 步骤五：权限配置 | 设置谁能看、谁能改 |
| 步骤六：更新频率 | 定义数据更新频率和更新机制 |
| 步骤七：测试验证 | 验证检索效果、准确率 |

## 三、知识库配置模板

| 知识库名称 | 所属智能体 | 来源 | 内容 | 数据权限 | 更新频率 | 状态 |
|---|---|---|---|---|---|---|
| 公司资质库 | 招投标智能体 | 内部 | 营业执照、资质证书、认证、专利 | 全员可见 | 资质变更时 | 已配置 |
| 成功案例库 | 招投标智能体 | 内部 | 历史中标项目、客户、规模、成果 | 按部门分级 | 每季度 | 已配置 |
| 招投标法规库 | 招投标智能体 | 外部 | 政府采购法、招投标法、行业规则 | 全员可见 | 政策更新时自动爬取 | 已配置 |

## 四、数据质量要求

| 项 | 要求 |
|---|---|
| 数据权限 | 智能体只能看它该看的（科室 Agent 不能看全院） |
| 数据时效 | 引用的制度是最新版，不是去年的 |
| 数据结构 | 表格层级、条款结构、段落语义，不能按纯文本切片 |
| 数据安全 | 敏感数据脱敏、权限分级、访问日志可追溯 |

## 五、切片规则详解

- 表格数据：按表格结构切片，保留表头、列名、行数据的关系
- 条款数据：按条款层级切片（一级条款、二级条款、三级条款）
- 段落数据：按语义段落切片，不按固定字数切

| 数据类型 | 切片规则 | 示例 |
|---|---|---|
| 表格数据 | 一个表格一个切片 | 门诊量统计表 |
| 条款数据 | 一个完整条款一个切片 | 第三章第十条 |
| 段落数据 | 按语义段落，200-500字 | 政策解读段落 |

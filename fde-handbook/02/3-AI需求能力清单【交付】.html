二、AI能力详细定义

2.1 自然语言问数

定义项

内容

能力描述

用户用自然语言提问（如"上个月门诊量多少"），系统理解意图，转化为数据查询，返回答案+图表

关联需求

REQ-001

输入

用户自然语言提问 + 指标口径库 + 数据源

输出

答案文本 + 可视化图表

效果指标

提问到出结果≤30秒，准确率≥95%

AI承担角色

语义解析 + 指标计算 + 图表生成

数据依赖

HIS指标数据（高依赖）、指标口径定义（高依赖）

验收口径

测试数据集____条，准确率≥____%，响应≤____秒，判定方：____

异常处理

无法理解提问→提示用户换种说法；查不到数据→返回"暂无数据"而非编造

2.2 自动报表生成

定义项

内容

能力描述

按预设模板自动汇总多源数据，生成标准化报表草稿，人工确认后发布

关联需求

REQ-002

输入

报表模板 + 多源数据（HIS/财务/质控）

输出

报表草稿（可编辑）

效果指标

生成≤10分钟，人工确认≤30分钟

AI承担角色

数据汇总 + 模板匹配 + 草稿生成

数据依赖

HIS数据（高）、财务数据（中）、质控数据（中）

验收口径

测试____批报表，生成≤____分钟，数据准确率≥____%

异常处理

数据源缺失→标注缺失项并生成部分报表，不阻塞

2.3 异常检测与归因

定义项

内容

能力描述

实时监控核心指标，发现异常自动分级，并追溯可能原因推送给责任人

关联需求

REQ-003

输入

指标实时数据 + 阈值规则 + 历史基线

输出

异常告警（分级）+ 归因分析报告

效果指标

检测延迟≤1天，归因维度≥3

AI承担角色

指标监控 + 异常检测 + 归因分析

数据依赖

实时指标数据（高）、历史数据（中）

验收口径

测试____条异常场景，检出率≥____%，归因维度≥____

异常处理

无法归因→标注"原因待查"，推送人工跟进，不编造原因

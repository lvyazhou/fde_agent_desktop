# 沧澜 AgentOS — 布局重设计方案

> 核心理念：**对话是主角，产出是舞台**。去掉传统 GUI 的冗余面板，让 AI 对话和产出物占满屏幕。

---

## 当前问题

```
┌─ 220px ─┬────── flex-1 ──────┬─ 280px ─┐
│ 会话列表  │      对话区         │ 智能体状态 │  ← 实际对话区只占 50%
│ (大部分空)│                    │ 技能标签  │  ← 右侧面板信息密度极低
│          │                    │ 空日志    │
│          │                    │ 空建议    │
└──────────┴────────────────────┴─────────┘
```

**问题**：500px 被两个侧面板吃掉，对话区被挤压。右侧面板内容空洞（"等待 Agent 活动..."），左侧会话列表大部分只有 1-2 个项目。

---

## 新布局方案

### 方案核心：去掉常驻侧面板，对话区占满

```
┌──────────────────────────────────────────────┐
│  ← 返回   我的电商系统   ⚡迭代中   ⚙️ 🔍    │  ← 紧凑项目头
├──────────────────────────────────────────────┤
│  ① ──── ② ──── ③ ──── ④ ──── ⑤             │  ← 步骤条（更紧凑）
├──────────────────────────────────────────────┤
│                                              │
│              全宽对话 / 产出区                  │  ← 占满剩余空间
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │  AI 回复（富媒体卡片嵌入）               │  │
│  │  ┌─────────────────────────────────┐   │  │
│  │  │  📋 功能清单预览（可展开收起）     │   │  │
│  │  └─────────────────────────────────┘   │  │
│  └────────────────────────────────────────┘  │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │  描述你的需求...              Enter 发送 ↑ │ │  ← 底部输入框
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

### 关键变化

| 元素 | 之前 | 之后 |
|------|------|------|
| **左侧会话列表** | 常驻 220px | 改为顶部下拉选择器（收起时 0px） |
| **右侧 InfoSidebar** | 常驻 280px | 改为右上角图标按钮触发的浮动面板 |
| **对话区** | 被挤压到 ~50% | 占满全宽（max-width: 800px 居中） |
| **步骤进度条** | 居中一行 | 更紧凑，和标题同行或缩小 |
| **功能清单/原型** | 独立 Tab 页面 | 嵌入对话流中的富媒体卡片 |

### 右侧信息改为"状态栏小组件"

不再用独立面板，而是在对话区顶部或输入框上方用紧凑的状态指示：

```
┌─────────────────────────────────────────────┐
│  🟢 沧澜 AI · MiniMax-M2.7 · 上下文 35%     │  ← 一行搞定
└─────────────────────────────────────────────┘
```

### 迭代优化页：保留两栏但更大气

```
┌─────────────────────┬───────────────────────┐
│                     │                       │
│     对话区 (50%)     │    实时预览 (50%)      │
│                     │                       │
│     更宽、更舒适      │    更大的预览窗口       │
│                     │                       │
└─────────────────────┴───────────────────────┘
```

不再有额外的侧面板挤压空间。

## 智能体驱动的交互模式

### 功能清单 — 不再是独立页面

AI 回复中直接嵌入可交互的功能清单卡片：

```
┌─────────────────────────────────────────────┐
│  🤖 AI: 已为你生成功能清单，包含 5 个模块：     │
│                                             │
│  ┌─────────────────────────────────────┐    │
│  │ 📋 电商管理系统 — 功能清单            │    │
│  │                                     │    │
│  │ 1. 商品管理  [P0]  ── 展开 ▸        │    │
│  │ 2. 订单管理  [P0]  ── 展开 ▸        │    │
│  │ 3. 多仓库存  [P1]  ── 展开 ▸        │    │
│  │ 4. 用户管理  [P1]  ── 展开 ▸        │    │
│  │ 5. 数据看板  [P2]  ── 展开 ▸        │    │
│  │                                     │    │
│  │ [导出 .md]  [导出 .docx]  [生成原型]  │    │
│  └─────────────────────────────────────┘    │
│                                             │
│  你可以说"把用户管理提升到 P0"来调整优先级      │
└─────────────────────────────────────────────┘
```

### 原型预览 — 对话中嵌入预览窗口

```
┌─────────────────────────────────────────────┐
│  🤖 AI: 原型已生成，共 7 个页面：              │
│                                             │
│  ┌─────────────────────────────────────┐    │
│  │  🌐 原型预览                  [全屏]  │    │
│  │  ┌─────────────────────────────┐    │    │
│  │  │                             │    │    │
│  │  │    (嵌入的 iframe 预览)       │    │    │
│  │  │                             │    │    │
│  │  └─────────────────────────────┘    │    │
│  │  页面: index orders products ...    │    │

```

### 导出 — 对话中的操作按钮

```
用户: 帮我导出项目

🤖 AI: 好的，你想导出什么？

  [📦 完整项目 ZIP]  [📄 功能清单 Word]  [🌐 浏览器打开原型]
```

## 步骤进度条优化

从"占一整行"改为"紧凑内联"：

```
之前: 
  ①────②────③────④────⑤    (独占一行，60px 高度)

之后:
  ← 返回  我的电商系统  ① · ② · ③ · ④ · ⑤  ⚡迭代中
  (和标题同行，节省垂直空间)
```

或者改为浮动在右上角的小型进度指示器。

---

## 实施建议

### Phase 1（快速见效）
- 右侧 InfoSidebar 改为默认隐藏，用图标按钮唤出
- 左侧会话列表改为默认隐藏
- 对话区占满全宽

### Phase 2（智能体驱动）
- 功能清单作为富媒体卡片嵌入对话流
- 原型预览作为可展开的嵌入窗口
- 导出作为对话中的快捷按钮

### Phase 3（极致体验）
- 步骤进度条内联到标题栏
- AI 状态栏变为一行紧凑指示
- 全面去除传统 GUI 操作，全部对话驱动

电商管理系统 — 功能清单

生成时间: 2026-06-02 21:05 | AI 模型: MiniMax-M2.7

1. 商品管理模块 P0 核心

1.1 商品 CRUD

  • 商品基本信息：名称、描述、分类、品牌
  • SKU 管理：多规格（颜色/尺码）、库存、价格
  • 商品图片：主图 + 详情图，支持拖拽排序
  • 商品状态：草稿 → 待审核 → 上架 → 下架

1.2 分类管理

  • 三级分类树：一级→二级→三级
  • 分类排序、图标配置

2. 订单管理模块 P0 核心

2.1 订单生命周期

  • 待支付 → 已支付 → 待发货 → 已发货 → 已签收 → 已完成
  • 支持取消、退款、退货退款三种逆向流程
  • 订单详情：商品信息、收货地址、物流追踪、操作日志

2.2 批量操作

  • 批量发货（Excel 导入运单号）
  • 批量打印面单

3. 多仓库存模块 P1 重要

  • 仓库管理：仓库信息、地址、负责人
  • 库存同步：各仓库独立库存，支持安全库存预警
  • 调拨单：仓间调拨申请 → 审批 → 出库 → 入库

4. 用户管理模块 P1 重要

  • 用户列表：注册信息、订单统计、消费金额
  • 会员等级：普通→银牌→金牌→钻石，不同折扣
  • 用户画像：消费偏好、活跃度标签

5. 数据看板模块 P2 后续

  • 核心指标卡片：GMV、订单量、客单价、转化率
  • 趋势图：日/周/月销售趋势
  • 商品排行：热销 Top 10、滞销预警
